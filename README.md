# Human Brain Lecture

뇌 과학 강의 및 실습 자료 저장소

## 프로젝트 개요

이 저장소는 fMRI, DTI 등 뇌 영상 분석을 위한 코드와 데이터 전처리 스크립트를 포함합니다.

## 디렉토리 구조

```
human_brain_lecture/
├── data/               # 원본 데이터 (gitignore에 포함)
├── scripts/            # 전처리 및 분석 스크립트
├── results/            # 분석 결과
└── docs/               # 문서 및 노트
```

## 사용된 도구

- SPM12 (Statistical Parametric Mapping)
- MATLAB
- Python (데이터 시각화)
- DSI Studio (확산 텐서 영상 분석)

## 시작하기

### 필요 사항

- MATLAB (SPM12 실행용)
- Python 3.11 이상
- DSI Studio

### 설치 방법

1. 저장소 클론
```bash
git clone https://github.com/taeyanglee01/human_brain_lecture.git
cd human_brain_lecture
```

2. Python 패키지 설치
```bash
pip install -r requirements.txt
```
